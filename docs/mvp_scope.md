# MVP Scope

## Project Goal

MathResearch Studio v1 is an AI-powered research workspace for mathematics researchers. Its goal is not to solve mathematics automatically, but to assist researchers throughout the literature workflow by helping them upload papers, extract structure, search content, ask grounded questions, and export organised notes.

## Version 1 Features

The Version 1 MVP focuses on one complete and practical workflow for mathematical literature analysis.

### Features

- PDF upload
- Text extraction
- Section detection
- Search
- AI assistant
- Notes export

### Feature Notes

- **PDF upload**: Allow users to upload research papers into the workspace.
- **Text extraction**: Extract readable text from uploaded PDF documents.
- **Section detection**: Detect and separate major sections such as definitions, theorems, lemmas, and proofs where possible.
- **Search**: Support search across uploaded papers and extracted content.
- **AI assistant**: Answer user questions using only the uploaded paper collection as context.
- **Notes export**: Export structured research notes for later study or writing.

## Features Intentionally Postponed to Version 2

The following features are valuable, but are intentionally postponed so that Version 1 remains focused and achievable.

- Advanced theorem dependency visualisation
- Rich interactive graph exploration
- Cross-paper notation normalisation at a deeper semantic level
- Multi-user collaboration features
- Automated literature recommendation
- Support for larger research knowledge bases at scale
- Fine-grained proof analysis and proof mining workflows
- Integration with external academic APIs and citation platforms
- Advanced annotation and manuscript drafting assistance

## Success Criteria for Version 1

Version 1 will be considered successful if it can reliably support the following workflow:

- A user can upload mathematical research papers in PDF format.
- The system can extract usable text from those papers.
- The system can identify meaningful structural sections from the extracted content.
- A user can search across the uploaded papers and retrieve relevant information.
- The AI assistant answers questions grounded only in the uploaded documents.
- A user can export structured notes from the processed material.
- The repository is organised clearly enough to demonstrate sound software engineering practice and portfolio value.
